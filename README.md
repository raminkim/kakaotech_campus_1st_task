# kakaotech_campus_1st_task
카카오테크 캠퍼스 1번째 과제

## Lv 1. 클래스 없이 기본적인 연산을 수행할 수 있는 계산기 만들기 (CalculatorLv1.java)

### 주요 기능

* 덧셈 (`+`), 뺄셈 (`-`), 곱셈 (`*`), 나눗셈 (`/`) 연산을 지원합니다.
* 사용자가 `"exit"`를 입력하기 전까지 계속해서 계산을 수행할 수 있습니다.

### 가정

* 입력받는 첫 번째와 두 번째 숫자는 항상 정수(`int`) 타입으로 간주합니다.

## 오류 처리

다음과 같은 경우 오류 메시지가 출력됩니다.

- **유효하지 않은 연산 기호:**
    - 연산 기호로 `+`, `-`, `*`, `/` 외의 다른 문자나 기호를 입력한 경우, `"적절한 연산 기호가 아닙니다"` 라는 메시지가 출력됩니다.
- **0으로 나누기:**
    - 나눗셈 연산 (`/`) 시 두 번째 숫자로 `0`을 입력한 경우, `"분모에 0이 입력될 수 없습니다"` 라는 메시지가 출력됩니다.
