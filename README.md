# kakaotech_campus_1st_task
카카오테크 캠퍼스 1번째 과제

## Lv 1. 클래스 없이 기본적인 연산을 수행할 수 있는 계산기 만들기 (CalculatorLv1.java)

### 주요 기능

-   덧셈 (`+`), 뺄셈 (`-`), 곱셈 (`*`), 나눗셈 (`/`) 연산을 지원합니다.
-   사용자가 `"exit"`를 입력하기 전까지 계속해서 계산을 수행할 수 있습니다.

### 가정

-   입력받는 첫 번째와 두 번째 숫자는 정수(`int`) 타입으로 간주합니다.
-   나눗셈에서 두 번째 인자가 0인 것을 처리해 주는 것 외에 별도의 오류 처리 기능은 없으며, 잘못된 입력 시 프로그램이 예기치 않게 종료될 수 있습니다.

## Lv 2. 클래스를 적용해 기본적인 연산을 수행할 수 있는 계산기 만들기 (CalculatorLv2.java)

### 주요 기능

-   덧셈 (`+`), 뺄셈 (`-`), 곱셈 (`*`), 나눗셈 (`/`) 연산을 지원합니다.
-   연산 결과들을 `List<Integer>` 타입인 변수 `resultList`에 저장합니다.
-   해당 `resultList` 변수는 Getter/Setter 메서드를 통해 접근/수정할 수 있습니다.
-   `removeResult` 메서드를 통해 `resultList`에 저장된 연산 결과들 중 가장 먼저 저장된 데이터를 삭제할 수 있습니다.
-   사용자가 `"exit"`를 입력하기 전까지 계속해서 계산을 수행할 수 있습니다.

### 가정

-   입력받는 첫 번째와 두 번째 숫자는 정수(`int`) 타입을 기대합니다.

### 오류 처리

다음과 같은 경우 지정된 오류 메시지가 출력됩니다.

-   **올바르지 않은 입력:**
    -   숫자 입력 시 정수 형태가 아닌 입력을 한 경우, `"올바른 입력이 아닙니다."` 라는 오류 메시지가 출력됩니다.
-   **유효하지 않은 연산 기호:**
    -   연산 기호로 `+`, `-`, `*`, `/` 외의 다른 문자나 기호를 입력한 경우, `"적절한 연산 기호가 아닙니다."` 라는 오류 메시지가 출력됩니다.
-   **0으로 나누기:**
    -   나눗셈 연산 (`/`) 시 두 번째 숫자로 `0`을 입력한 경우, `"분모에 0이 입력될 수 없습니다."` 라는 오류 메시지가 출력됩니다.

## Lv 3. Enum, 제네릭, 람다 & 스트림을 활용한 계산기 만들기 (CalculatorLv3.java)

### 주요 기능

-   덧셈 (`+`), 뺄셈 (`-`), 곱셈 (`*`), 나눗셈 (`/`) 연산을 지원합니다.
-   연산 결과들을 `List<Double>` 타입인 변수 `resultList`에 저장합니다. (*Lv2와 달리 실수 결과를 저장*)
-   해당 `resultList` 변수는 Getter/Setter 메서드를 통해 접근/수정할 수 있습니다.
-   `removeResult` 메서드를 통해 `resultList`에 저장된 연산 결과들 중 가장 먼저 저장된 데이터를 삭제할 수 있습니다.
-   `printResultsGreaterThan` 메서드를 통해 `resultList`에 저장된 연산 결과들 중 인수로 받은 기준값(`standard`)보다 큰 결과 값들을 출력할 수 있습니다.
-   사용자가 `"exit"`를 입력하기 전까지 계속해서 계산을 수행할 수 있습니다.

### 가정

-   입력받는 첫 번째와 두 번째 숫자에 대해 실수형(`double`) 입력을 지원합니다.

### 오류 처리

다음과 같은 경우 지정된 오류 메시지가 출력됩니다.

-   **올바르지 않은 입력:**
    -   숫자 입력 시 정수 형태가 아닌 입력을 한 경우, `"올바른 입력이 아닙니다."` 라는 오류 메시지가 출력됩니다.
-   **유효하지 않은 연산 기호:**
    -   연산 기호로 `+`, `-`, `*`, `/` 외의 다른 문자나 기호를 입력한 경우, `"적절한 연산 기호가 아닙니다."` 라는 오류 메시지가 출력됩니다.
-   **0으로 나누기:**
    -   나눗셈 연산 (`/`) 시 두 번째 숫자로 `0` 또는 `0.0`을 입력한 경우, `"분모에 0이 입력될 수 없습니다."` 라는 오류 메시지가 출력됩니다.
